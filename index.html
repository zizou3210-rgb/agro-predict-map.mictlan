Top Germplasm

AI-ranked germplasm candidates for the active target

This workspace view uses AI-driven modeling to identify the germplasms with the strongest expected performance for the current target defined by the user. To make that ranking more agronomically robust, the app reconstructs the recent environmental context of each germplasm by downloading climate raster information across the same phenological windows for the previous 5 years and by enriching every record with soil data before applying the workspace model.

The map emphasizes the highest-potential candidates, while the download preserves the full prediction set used to generate this analysis.

Manual Regional Bounds

Define a manual bounding box over Africa. The app will generate a climate grid inside the box, take the centroid of each cell, create one prediction point per centroid and original germplasm row, and use those centroid coordinates for climate raster extraction.

Start map selection, then drag directly on the map to define the bounding box.

Enter latitude and longitude bounds to preview the climate grid inside the bounding box.

Forecast Dates

When you reuse a saved model, choose the planting and harvesting dates. The preprocess climate stage will build climate windows using these dates and the 5-year backward average.
